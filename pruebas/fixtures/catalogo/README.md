# Imágenes del catálogo de prueba

Las 28 imágenes de los productos públicos de prueba del prototipo aprobado (`window.RECURSOS.catalogo`), extraídas en JG-04 con `node scripts/extraer-recursos-prototipo.mjs` (specs/16, decisión 77). Son los mismos bytes WebP del prototipo, de 560 × 560 px.

**Solo para la semilla de demostración y las pruebas:** nunca se sirven desde `public/`. Las imágenes reales del catálogo las sube INCOVSA desde el panel.
